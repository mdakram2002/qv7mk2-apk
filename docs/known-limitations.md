# Known limitations

- **Forecast history may be incomplete.** The committed publication search starts on 18 December 2025. The earliest retrieved forecast for January delivery was published on 30 December, and the longest observed lead was 66.5 hours. The search covers the records observed, but cannot prove that older archive versions do not exist before its start date.
- **The cutoff is an assumption.** The default is 10:00 Europe/London on the day before delivery. It can be changed, but has not been confirmed as a procurement gate or contractual deadline.
- **The data was processed from the committed cache.** A read-only live sample check on 24 October 2026 returned HTTP 200 from both official dataset stream routes with the expected fields. The full-month dataset was not downloaded again during that check; the checked-in raw files were reprocessed from cache. The report records the retrieval windows and source retrieval time.
- **The two datasets have different resolutions.** The cached WINDFOR data has 744 hourly delivery starts. FUELHH has 1,488 half-hour actual records. WindLens averages each pair of half-hour actual MW readings for the hourly comparison. At the default cutoff, all 1,488 actual records, 744 eligible forecasts, and 744 hourly matches are present in the cache. If either actual in an hour is missing, the hourly actual is left unavailable. Forecasts are not copied or interpolated.
- **This is a small analytical service.** The API loads CSV data into memory and is intended for this January analysis, not high-concurrency operational use.
- **Runtime file changes may not persist on Render.** The Docker image includes the checked-in files. Render's default filesystem is temporary, so configure persistent storage if ingestion needs to write data that survives a new deployment.
- **The public deployment needs a fresh verification.** On 24 October 2026, the Vercel home page and Render health and summary endpoints returned HTTP 200. Render health said `ready: true`, but the summary still used the older 50% half-hour denominator and previous scores. A direct Vercel `/about` request returned 404. The SPA rewrite and updated analysis are in the repository and need to be deployed before those routes and values can be checked again. Public exports and incognito access have not been verified.

- **The demo is still outstanding.** No video has been recorded or uploaded.
