# Customer demo script (under five minutes)

1. Introduce WindLens as a January 2026 review of the official national wind forecast available for a configurable D-1 purchasing decision.
2. Show the cutoff control. Explain that 10:00 Europe/London is a transparent analytical assumption and can be changed.
3. Review MAE, RMSE, bias and WAPE alongside sample count and coverage. Explain positive bias as over-forecasting.
4. Use the forecast versus actual view and daily accuracy trend to identify variation through the month. Point out that missing coverage remains visible.
5. Open Intervals to inspect a timestamp, forecast, actual, signed error and forecast publish time; export the rows to CSV.
6. Open Forecast history to show eligible and post-cutoff versions, explaining how the cutoff prevents look-ahead bias.
7. End on Data quality and source provenance. Do not describe unavailable metrics as results.
